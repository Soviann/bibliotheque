# CONTEXT.md — Ubiquitous Language & Domain Glossary

This document pins down the ubiquitous language for the Bibliotheque project, providing the exact mapping between French business concepts and English code identifiers.

## Core Entities & Concepts

| French Business Term | English Code Identifier | Definition & Invariants |
|----------------------|-------------------------|--------------------------|
| **Série** | `ComicSeries` | The aggregate root representing a publication run. Holds metadata (title, status, type, publisher, cover, authors) and cascading collection of tomes. Soft-deletable (`deletedAt`). |
| **Tome** | `Tome` | An individual book/volume in a series. Has a `number` (and optional `tomeEnd` for bundled volumes), `isbn`, `title`, and three tracking booleans (`bought`, `onNas`, `read`). |
| **Auteur** | `Author` | Creator/writer/illustrator associated Many-to-Many with series. Unique by `name`. Can be flagged `followedForNewSeries` for automated monitoring of upcoming series. |
| **Proposition d'enrichissement** | `EnrichmentProposal` | Metadata enhancement candidate generated by lookups. Carries field, old/new JSON values, confidence (`HIGH`, `MEDIUM`, `LOW`), and status (`PENDING`, `ACCEPTED`, `REJECTED`, `PRE_ACCEPTED`). |
| **Suggestion de série** | `SeriesSuggestion` | AI recommendation of a new series based on user reading tastes, with link to source series and review status (`PENDING`, `ADDED`, `DISMISSED`). |
| **Notification** | `Notification` | System alert delivered in-app and optionally via Web Push for missing tomes, new releases, author series, and enrichment reviews. |

## Volume Tracking Statuses

Each `Tome` possesses three independent tracking booleans:
- **Acheté (`bought`)**: Physical copy or digital purchase owned by the user. If `false`, the tome qualifies for the **ToBuy** (`/to-buy`) acquisition view.
- **Sur le NAS (`onNas`)**: Digital scan or ebook file present on the local Synology NAS storage. If `false`, the tome qualifies for the **ToDownload** (`/to-download`) acquisition view.
- **Lu (`read`)**: User has finished reading the tome. Drives reading progress calculations.

Default values when creating new tomes in a series are governed by the series-level preferences:
`defaultTomeBought`, `defaultTomeOnNas`, `defaultTomeRead`.

## Series Statuses (`ComicStatus`)

| Status | Code Case | Meaning |
|--------|-----------|---------|
| **En cours** | `BUYING` | Ongoing or actively collected series. Monitored for new volume releases. |
| **En cours de téléchargement** | `DOWNLOADING` | Actively monitored for digital downloads or scans on NAS storage. |
| **Terminée** | `FINISHED` | Fully collected series; publication ended and all tomes are owned. |
| **Abandonnée** | `STOPPED` | User stopped collecting; excluded from new release monitoring and missing tome alerts. |
| **Liste d'envies** | `WISHLIST` | Series of interest not yet purchased; displayed with wishlist filters. |

## Series Types (`ComicType`)

| Type | Code Case | Description & Lookup Nuance |
|------|-----------|-----------------------------|
| **BD** | `BD` | Franco-Belgian comics. High lookup priority on Bedetheque and BNF. |
| **Comics** | `COMICS` | Western/American comic books. Priority on Bedetheque, OpenLibrary, and Google Books. |
| **Manga** | `MANGA` | Japanese manga and Asian manhwa/manhua. High lookup priority on AniList and Bedetheque. |
| **Livre** | `LIVRE` | Traditional novels, anthologies, or non-comic publications. Priority on Google Books, BNF, OpenLibrary. |

## Feature Domain Terminology

- **Lookup / Recherche de métadonnées**: Querying external bibliographic sources by ISBN or title to populate metadata (title, authors, cover, publisher, description).
- **Auto-Enrichment / Enrichissement automatique**: Background pipeline evaluating incomplete series, querying lookup providers, and either applying changes automatically (`HIGH` confidence) or creating review proposals (`MEDIUM` confidence).
- **Batch Lookup**: Tool allowing bulk metadata queries across all series missing data.
- **Series Merge / Fusion de séries**: Combining duplicate entries (e.g. split across BD/Manga or slightly different titles) into a single canonical series with unified tomes.
- **Quick Add / Ajout rapide**: High-speed collection workflow on mobile enabling continuous barcode scanning or rapid title searching to insert tomes without leaving the camera/search stream.
- **Web Share Target / Partage**: Native Android/PWA integration allowing external links (e.g. from bookstore or browser) to be shared into Bibliotheque to match or create a series.
- **Purge / Purge des corbeilles**: Automated or manual permanent deletion of soft-deleted series in trash past the retention threshold (default 30 days).
